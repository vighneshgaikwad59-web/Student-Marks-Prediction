# Student Marks Prediction using Scikit-learn

## Project Overview
This beginner-friendly machine learning project predicts student marks based on study hours using Linear Regression.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Workflow
1. Create a dataset.
2. Separate input features and target values.
3. Split data into training and testing sets.
4. Train a Linear Regression model.
5. Predict marks and evaluate model performance.
6. Visualize the results.


## Learning Outcomes
Learned basic data preprocessing, model training, prediction, evaluation, and visualization.
**Note:** This is an educational project using a small sample dataset. Predictions are not intended for real academic decisions.
